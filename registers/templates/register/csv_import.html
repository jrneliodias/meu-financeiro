CSV Format Guide

Required Columns

  • date - Date in YYYY-MM-DD format
  • description - Transaction description
  • amount - Transaction amount (numeric)

Optional Columns

  • category - Expense category
  • type - Transaction type (default: expense)
  • payment_method - Payment method
Example CSV Format:
date,description,amount,category,type,payment_method
2025-01-15,Grocery Store,45.67,Supermercado,expense,Crédito - Nubank
2025-01-16,Uber Trip,12.50,Uber,expense,Crédito - Nubank
